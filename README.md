# Travel Site Project

A frontend travel booking website developed using HTML, CSS, and JavaScript.

---

# Features

- Landing/Home page
- Adventure destination listings
- Adventure detail pages
- Reservation/booking section
- Responsive UI
- Dynamic content rendering using JavaScript

---

# Technologies Used

- HTML
- CSS
- JavaScript

---

# How to Run the Project Locally

## Step 1 — Extract the ZIP

Extract the project folder:

travel-site-main.zip

---

## Step 2 — Open Project Folder

Open the extracted folder in VS Code.

Example:

travel-site-main/

---

## Step 3 — Open Terminal

Inside VS Code terminal:

cd travel-site-main
